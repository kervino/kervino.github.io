# Publish Version 3 to GitHub Pages

1. Open https://github.com/kervino/kervino.github.io and make a backup of the existing repository.
2. Extract this ZIP. Upload its **contents**, not the ZIP or its enclosing folder, to the root of the main branch. Make sure index.html is in the repository root.
3. Commit as `Redesign portfolio — Version 3`.
4. Check Settings > Pages: Deploy from branch > main > /(root).
5. Visit https://kervino.github.io/ and check mobile and all project links.

This GitHub-ready copy is identical to the chosen V3 design except for a tiny mobile overflow correction. It does **not** contain the optional V3.1 mouse effects.

Before announcing your portfolio to recruiters, replace illustrative project screenshots and generic GitHub profile links with real project materials, and add your resume and contact information when verified.
