Behind the build.

The big idea

Spatial acceleration structures organize geometry so programs can avoid checking every object for every query. Two common approaches are bounding volume hierarchies (BVHs) and KD-trees.

Topics to document

  • How a scene is partitioned or grouped.
  • How queries traverse a hierarchy instead of scanning everything.
  • The trade-off between building a structure and using it for queries.
  • Visual examples and measured results from coursework.
