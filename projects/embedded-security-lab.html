Overview

This is an early-stage security learning project focused on understanding how embedded software and firmware images are structured, and how a vulnerability assessment is approached in a safe, controlled environment.

Implemented so far

  • Created a simple sample firmware filesystem layout.
  • Wrote a Python script to enumerate files recursively.
  • Printed paths relative to the firmware root and counted discovered files.

Why this project

I want to turn cybersecurity theory into practical, repeatable engineering exercises. Starting with basic inventory and filesystem analysis lays groundwork for identifying configurations, permissions, services, and potential security issues later.

Next steps

Expand the sample root filesystem, inspect configuration files, and develop a structured checklist for assessment. Findings will be documented as the lab progresses.

Status: early-stage. No vulnerability discoveries or full penetration-test capabilities are claimed.
