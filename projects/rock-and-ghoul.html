Overview

Rock & Ghoul is a 2D game developed as a team project using C++ and OpenGL. It is one of my projects exploring real-time interactive software through game development.

Technical focus

The project brought together graphics programming and gameplay in a real-time application. I used it to gain practical experience working on an interactive C++ codebase.

  • 2D rendering with OpenGL.
  • Interactive gameplay in C++.
  • Working within a shared team codebase.
