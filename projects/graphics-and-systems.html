Overview

My degree in Real-Time Interactive Simulation includes hands-on work in C++ and interactive systems. These projects help connect programming fundamentals with graphics, performance, and the way complex software components interact.

Areas explored

  • Rendering with OpenGL and programmable shading.
  • Environment mapping and visual effects experiments.
  • Real-time interactive projects built with C++.
  • Supporting systems concepts such as data structures and performance.

What I learned

Graphics work reinforces debugging discipline, careful data layout, and the importance of understanding the full path from CPU-side structures to GPU-side output. Systems coursework adds a performance and correctness perspective.
