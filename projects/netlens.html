Overview

I built NetLens to revisit network traffic analysis and practice turning packet data into something more readable. It works with saved PCAP files, so I can inspect captures locally without stepping through every packet manually.

Features implemented

  • Read saved PCAP files and summarize TCP, UDP and other packets.
  • Report source and destination IPv4 addresses and transport-layer ports.
  • Print traffic summaries and save human-readable text and JSON reports.
  • Handle invalid capture files gracefully and test parsing and export behavior.

How it works

NetLens uses Python and Scapy to read packets from a capture file. It checks the available network and transport layers, then collects protocol counts, IP addresses and port information. The summaries can be reviewed in the terminal or exported as text and JSON reports.

Testing & results

I tested the analyzer with sample captures containing TCP, UDP and other traffic. In one 56-packet sample, NetLens counted 34 TCP packets, 18 UDP packets and 4 other packets. I also tested invalid-file handling and report generation with automated tests.

What I learned

This project gave me more practice with packet structures, Python automation, error handling and writing tests. It also reminded me how useful a small command-line tool can be when it answers a specific question quickly.

NetLens is an offline traffic-analysis learning project, not a production intrusion-detection system.
