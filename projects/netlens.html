Overview

Raw packet captures contain useful information, but they can be hard to scan quickly. NetLens is a command-line project that reads PCAP files, groups traffic by protocol, and surfaces useful endpoint and port information in a compact report.

What I built

  • Summarizes captured TCP, UDP, and other traffic.
  • Reports source and destination IP addresses and common ports.
  • Exports structured JSON reports for later processing.
  • Handles invalid capture input and includes unit tests for parsing and reporting.

Technical approach

The tool reads capture data, extracts packet attributes, groups useful information into summaries, and writes results in human-readable and JSON formats. The emphasis is on readable code, predictable error handling, and building a tool that can evolve in stages.

Next steps

Add richer protocol analysis, filtering options, and more representative test fixtures as the project develops.

The project is a learning tool and analysis prototype, not a production intrusion-detection system.
