Behind the build.

The problem

A dot product adds together pairwise products from two arrays. The mathematical idea is simple, but the implementation can be used to explore how processors execute code.

Approaches explored

  • Scalar: a straightforward loop as a baseline.
  • Loop unrolling: multiple partial sums to reduce serial dependencies.
  • SSE2 SIMD: vector instructions to perform several operations in parallel.
  • pthreads: dividing array ranges across workers and combining partial results.

What I learned

Optimization is not the same as making source code look shorter. Correctness, memory access, instruction dependencies and measurement all matter. Comparing approaches helps connect C code with how the underlying hardware behaves.
