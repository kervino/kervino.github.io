Overview

Wayforge is a collaborative indoor navigation project. It brings together a building editor, a navigation web application, a backend service, and a native C++ routing engine.

My responsibility is to connect the web applications to the routing engine through backend interfaces, allowing the different components to communicate and process navigation requests.

My contributions

  • Set up the Node.js and TypeScript backend development environment.
  • Integrated calls to the native routing engine's command-line interface.
  • Tested building registration, publishing, and route queries end to end.
  • Validated step-free route requests through the API.
  • Documented the backend integration so teammates could connect their components.

Engineering focus

One of the main challenges is integrating components developed by different members of the team.

Building layouts originate from the studio application, route calculations are handled by the C++ engine, and the backend exposes these functions to the navigator interface.

Maintaining clear API contracts and testing each connection helps identify integration issues before they affect the complete navigation workflow.

Next steps

Complete integration with building layouts generated by the studio application and connect the backend to the navigator frontend as those components are finalized.

Wayforge is a collaborative academic project. This page focuses on my backend and integration responsibilities rather than the entire team's work.
