Behind the build.

The context

Wayforge is a team software project involving a native C++ library and a Unity-facing integration layer. The challenge is getting different parts of the stack to work together predictably, not just writing code that compiles in isolation.

My involvement

In my RTIS 2 work, I have been working through the native API and Unity bridge, examining how managed C# code calls into compiled C++ functionality.

  • Worked with native C API declarations and implementation details.
  • Set up and checked Unity integration using a native plugin and C# bridge.
  • Built and tested a Windows x64 version and worked through the Android native build workflow.
  • Used CMake, Visual Studio, Git and automated test runs to validate parts of the system.

What makes it interesting

Interop work forces you to think clearly about data boundaries, library loading, platform builds and error handling. A mistake in one layer can look like a bug somewhere completely different.

What I am working on next

Continuing to improve the integration, error handling and documentation as the project evolves. Screenshots, diagrams and repo details can be added once they are ready and approved for sharing.
