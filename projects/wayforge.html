Overview

Wayforge is a team project for indoor navigation. The system brings together a building editor, a navigation web app, a backend service, and a native routing engine. My area of responsibility is connecting the web-facing components to routing functionality through backend interfaces.

My contributions

  • Set up the Node.js and TypeScript backend development environment.
  • Integrated calls to the native routing engine command-line interface.
  • Tested building registration, publishing, and route queries end to end.
  • Validated a step-free route request through the API and documented the integration for teammates.

Engineering focus

The challenging part is coordinating data across independently developed components: building files created in the studio, engine API responses, backend endpoints, and the navigator UI. A clear interface contract reduces integration surprises.

Next steps

Complete integration with real building layouts from the studio website and the navigator frontend as those components are finalized.

This is a collaborative academic project. The description focuses on my backend and integration responsibilities, not the entire team’s work.
